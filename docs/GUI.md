# GUI 键盘操作指南（docs/GUI.md）

GUI 是纯键盘操作的网页：所有控件都是原生表单元素（Tab 键即可到达全部功能），另有全局快捷键；鼠标操作已完全禁用（纯键盘）。

## 启动

    ./wos -addr :8080     # 打开 http://localhost:8080

首屏自动加载「透镜聚焦（艾里斑）」示例并开始计算。

## 快捷键总表（随时按 ? / F1 查看）

| 键 | 功能 |
|---|---|
| Tab / Shift+Tab | 焦点移动（全部功能都可通过 Tab 完成） |
| f | 逐个定位参数：当前元件各参数 → 光源各参数 → 全局各参数 → 元件列表（循环；输入框内按 f 同样生效，不输入字符） |
| 空格 / Ctrl+Enter | 运行模拟 |
| ↑ / ↓ | 选择上一个/下一个元件 |
| Shift+↑ / Shift+↓ | 调整元件顺序 |
| i | 插入元件（对话框内：打字过滤，↑↓ 选择，Enter 插入） |
| d / Delete | 删除当前元件 |
| q / e | 上一个 / 下一个输出平面 |
| 1–5 | 视图：1 总强度、2 |Ex|²、3 |Ey|²、4 相位 Ex、5 相位 Ey |
| p | 一维剖面开/关 |
| x / y | 剖面方向（横向/纵向） |
| l | 强度视图对数/线性切换 |
| a | 自动运行开关（参数修改后 350ms 自动重算） |
| j | 高级模式：直接编辑配置 JSON（Ctrl+Enter 应用） |
| n | 新建空白光路 |
| o | 打开 JSON 配置文件 |
| s | 把当前配置保存为 JSON 文件（浏览器下载） |
| Esc | 关闭对话框 / 返回上一层光路（反射臂内） |
| ? / F1 | 帮助 |

焦点位于输入框/下拉框内时，键盘完全交还给浏览器原生行为：数字框可直接输入任意数值（**支持科学计数法**，如 `1e-3`、`632.8e-9`）、↑/↓ 按步长步进，Enter 确认并移出焦点；文本/下拉/复选框同理。全局快捷键（q/e/n/o/s 等）统一在焦点离开表单控件后生效——调整完参数按 Enter（或 Tab）移出焦点即可继续使用全局键。例外：f 定位在所有输入控件内都生效且不输入字符（文本框/标签中需要字母 f 时请用 j JSON 编辑器修改）。数字框输入为空或非法（如残缺的 `2e-`）时不会写入配置，而是回退为当前值。

## 工作流

1. **搭光路**：光路编辑器按顺序列出元件；↑↓ 选中，i 插入（光源→透镜→传播→探测器是基本骨架）。
2. **调参数**：选中元件后参数面板出现（纯数值输入框，无滑杆）；f 键一键定位到参数，数值框支持科学计数法直接输入（如 `1e-3`）、↑/↓ 步进，Enter 确认并移出焦点，修改后 350ms 自动重算。参数来自内核目录，任意元件参数均可调。
3. **看结果**：q/e 切平面，1–5 切视图，p 叠加剖面，l 换标度；指标（功率/峰值/质心/RMS/Strehl）实时显示。
4. **干涉仪**：分束器参数面板有「编辑反射臂光路 →」进入子光路（Esc 返回）；合束器面板编辑各端口权重（arm 下拉 + 复权重）。
5. **高级**：j 打开 JSON 编辑器直接改任意配置（包括 GUI 未暴露的字段），Ctrl+Enter 应用。
6. **示例**：`examples/presets/` 目录内置 13 个 JSON 预设文件（高斯、艾里斑、单缝、双缝、光栅、圆孔、波带片、涡旋、偏振、马赫-曾德尔、迈克尔逊、贝塞尔、像差），按 o 打开对应文件载入。
7. **文件**：n 新建空白光路；s 把当前配置下载为 JSON 文件（wos-config.json）；o 打开 JSON 配置文件载入（也可用 j 在 JSON 编辑器中粘贴）。

## 显示约定

- 强度视图：inferno 色图，默认对数标度（4 个数量级动态范围）。
- 相位视图：循环色图，−π…π。
- 剖面：叠加在当前视图上，标注数据范围与切割位置（3 像素平均）。
- 状态栏：计算耗时、网格、输出平面数、警告数；警告明细在右栏。
