# GUI 键盘操作指南（docs/GUI.md）

GUI 同时支持**鼠标与键盘**：所有控件都是原生表单元素（鼠标可直接点击，Tab 键亦可到达全部功能），另有全局快捷键。页面为**天蓝色**浅色主题，两栏布局——左侧「光路编辑器」（波动模式另含全局参数/光源/警告）与右侧**放大的「输出」区**。波动光学与量子光学**共用同一输出区**，选择哪种模式就**只显示**哪种模式的内容（m 键或顶部按钮切换）。

## 启动

    ./wos -addr :1120     # 打开 http://localhost:1120

首屏自动加载「透镜聚焦（艾里斑）」示例并开始计算。**运行按钮（▶ 运行）在右上角「? 帮助」旁边**；修改参数后**不会自动重算**，需手动点「▶ 运行」或按空格。

## 快捷键总表（随时按 ? / F1 查看）

| 键 | 功能 |
|---|---|
| Tab / Shift+Tab | 焦点移动（全部功能都可通过 Tab 完成） |
| f | 逐个定位参数：当前元件各参数 → 光源各参数 → 全局各参数 → 元件列表（循环；输入框内按 f 同样生效，不输入字符） |
| ▶ 运行 / 空格 / Ctrl+Enter | 运行模拟（修改参数后不自动运行） |
| ↑ / ↓ | 选择上一个/下一个元件 |
| Shift+↑ / Shift+↓ | 把当前元件沿光轴前后移动 5 mm（光路顺序由位置决定） |
| i | 插入元件（对话框内：打字过滤，↑↓ 选择，Enter 插入） |
| d / Delete | 删除当前元件 |
| q / e | 上一个 / 下一个输出平面 |
| 1–8 / 0 | 视图：1 图像、2 相位（去包裹）、3 偏振、4 |Ex|²、5 |Ey|²、6 |Ez|²、7 相位 Ex、8 相位 Ey、0 立体视图 |
| c | 切换通道：全部光源（合成）↔ 各光源单元（多光源时才有多项） |
| 鼠标（图像上） | **点击**该点即在此处读取偏振态（ψ/χ/轴比/手性/DOP）、斯托克斯参数、琼斯矢量与相位（含波前 PV/RMS，单位 λ），并在图上标出细十字；未点击时下方只显示提示 |
| 鼠标（立体视图） | 拖动旋转、滚轮缩放、右键/Shift 拖动平移、双击复位；拖动方向默认「反向」（画面跟着指针走），左下角小按钮可切换并记忆 |
| p | 一维剖面开/关 |
| x / y | 剖面方向（横向/纵向） |
| l | 对数/线性标度切换 |
| a | 自动运行开关（**默认关闭**） |
| j | 高级模式：直接编辑配置 JSON（Ctrl+Enter 应用） |
| n | 新建空白光路 |
| o | 打开 JSON 配置文件 |
| s | 把当前配置保存为 JSON 文件（浏览器下载） |
| Esc | 关闭对话框 |
| m | 波动光学 / 量子光学 模式切换 |
| ? / F1 | 帮助 |

焦点位于输入框/下拉框内时，键盘完全交还给浏览器原生行为：数字框可直接输入任意数值（**支持科学计数法**，如 `1e-3`、`632.8e-9`）、↑/↓ 按步长步进，Enter 确认并移出焦点；文本/下拉/复选框同理。全局快捷键（q/e/n/o/s 等）统一在焦点离开表单控件后生效——调整完参数按 Enter（或 Tab）移出焦点即可继续使用全局键。例外：f 定位在所有输入控件内都生效且不输入字符（文本框/标签中需要字母 f 时请用 j JSON 编辑器修改）。数字框输入为空或非法（如残缺的 `2e-`）时不会写入配置，而是回退为当前值。

## 工作流

1. **搭光路**：光路编辑器的元件列表用于编辑，**光路顺序由元件位置（z）决定**。↑↓ 选中元件；i 插入（新元件自动落在当前元件与沿 z 的下一个元件之间）；参数面板可直接编辑元件的 x/y/z（mm）、yaw/pitch/roll（度）与形状尺寸（如圆孔半径、双缝缝宽/缝距）；Shift+↑/↓ 沿光轴微调位置。典型骨架：光源 → 透镜 → 探测器。
2. **调参数**：选中元件后参数面板出现（纯数值输入框，无滑杆）；f 键一键定位到参数，数值框支持科学计数法直接输入（如 `1e-3`）、↑/↓ 步进，Enter 确认并移出焦点。修改参数后**不自动重算**——点右上角「▶ 运行」或按空格运行。参数来自内核目录，任意元件参数均可调。
3. **看结果**：q/e 切平面，1–8/0 切视图（**1 图像**＝真实光色与明暗、**2 相位**＝去包裹波前、**3 偏振**＝方位角着色＋椭圆阵列、**0 立体视图**＝整套光路三维渲染），p 叠加剖面，l 换标度，c 切换光源通道；指标（功率/峰值/质心/RMS/Strehl）、各光源通道功率与鼠标处偏振/相位实时显示。
4. **干涉仪**：直接在平台上摆分束器（yaw=45°）与两块反射镜即可，折返与合束由几何自动推导；等臂时暗口为零，给某臂反射镜加一点 yaw/pitch 倾斜即可看到等厚干涉条纹（见模板「迈克尔逊干涉仪」）。
5. **高级**：j 打开 JSON 编辑器直接改任意配置（包括 GUI 未暴露的字段），Ctrl+Enter 应用。
6. **模板**：左上「模板…」下拉内置 16 套光路，**全部是定位场景**——干涉仪（迈克尔逊、马赫-曾德尔）、远场衍射（光栅光谱、圆孔艾里斑、单缝、双缝）、聚焦（透镜艾里斑、波带片、泽尼克像差、贝塞尔、涡旋）、光束与偏振（高斯、双光源双波长、偏振与相位、偏振片与波片）与直线光路。远场类模板一律采用**傅里叶透镜 + 焦面探测器**：固定网格无法表示大距离上的远场（级次/光斑既细于像素又宽于窗口），透镜把远场搬到焦面后 x_q = q·f·λ/Λ、光斑 λf/D 才能同时被窗口容纳与被网格解析。示例不再随包分发为 .json 文件；旧版本（0.x/1.0 的 elements 元件序列）配置仍可按 o 打开，载入时自动转换为定位场景并提示。
7. **文件**：n 新建空白光路；s 把当前配置下载为 JSON 文件（wos-config.json）；o 打开 JSON 配置文件载入（也可用 j 在 JSON 编辑器中粘贴）。

## 量子光学模式（m 切换）

量子模式与波动光学共用左侧「光路编辑器」与中间「输出框」：左侧设置**模式数 / 截断**、**初态**（真空 / Fock / 相干 / 压缩真空 / 双模压缩 / 热态）与**门序列**（相移 / 分束器 / 位移 / 压缩 / 损耗），点右上角「▶ 运行」（或空格）计算。右侧输出框显示：

- 每模 **平均光子数** ⟨n⟩、**g²(0)**、光子数分布 P(n) 柱状图、正交分量均值/方差；
- 模式对的 **联合分布** P(na, nb)（Hong-Ou-Mandel 的符合计数可直接读出）。

**导出**：波动光学输出框顶部有「导出 SVG」按钮——把**X、Y 两个剖面曲线**同时导出为**纯矢量 SVG（1D polyline + 坐标轴/标签，上下两张子图）**，无位图封装；量子模式左侧有「导出 PNG / 导出 SVG」按钮（图表）。

## 显示约定

- 分量强度视图（|Ex|²、|Ey|²、|Ez|²）：inferno 色图，默认对数标度（4 个数量级动态范围）；图像视图给的是真实颜色与明暗，不用再单看总强度页。
- 相位视图：循环色图，−π…π。
- 剖面：叠加在当前视图上，标注数据范围与切割位置（3 像素平均）。
- 状态栏：计算耗时、网格、输出平面数、警告数；警告明细在右栏。

## 定位场景与立体视图

- 元件的位置（x/y/z，单位 mm）与朝向（yaw/pitch/roll，单位度）决定光路：光从光源出发沿方向传播，遇到最近命中的元件发生透射/反射/分束，直到被探测器接收。元件可以任意摆放、重叠光轴、折返、多次往返，顺序与列表顺序无关。
- **0 立体视图**把整套光路画成三维：元件按其轮廓与朝向画成板（法线小箭头指示朝向、命中元件的边框高亮），光束段按光源的真实颜色与相对功率着色，功率为零的段画成虚线（被遮挡）；拖动旋转、滚轮缩放、右键或 Shift 拖动平移、双击复位。左下角有 x/y/z 坐标指示。
- **拖动方向**：默认「反向」——画面跟着指针走（抓住转）。若你的习惯相反，点左下角提示条上的「拖动方向：反向/正向」小按钮切换，选择保存在浏览器本地（localStorage），下次打开自动沿用；双击复位只重置视角，不改这个偏好。
- 探测器的默认朝向是“正对沿 +z 来的光”（yaw=180°）；若把探测器摆到侧面或让光从背面入射，它不会记录（探测器只接收正面来光）。
- 立体视图里高亮（蓝色描边）的元件表示本次运行中被光束命中过，可用来判断光路是否按预期走。
- 浏览器标签页（tab）显示本项目图标：淡蓝底 + 白色光栅衍射强度曲线（`cmd/wos/web/favicon.svg`，SVG 矢量图标，仅出现在标签页中，不占用页面空间）。
